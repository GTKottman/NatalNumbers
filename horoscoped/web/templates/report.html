Calculation Pipeline
  1. Local time → UTC
    {{ local_str }} ({{ timezone }}) → {{ utc_str }}
  2. UTC → Julian Day
    JD = {{ "%.6f"|format(jd) }}
  3. Julian Day → n (days since J2000.0)
    n = JD − 2451545.0 = {{ "%.4f"|format(jd - 2451545.0) }}
  4. Ephemeris position for each body
    λ = PyEphem apparent geocentric ecliptic longitude, normalized to 0° ≤ λ < 360°
  5. Zodiac sector
    sector = ⌊ λ ÷ 30 ⌋ maps each longitude to one of twelve 30° tropical arcs.
  6. Degree inside the sign
    degree = λ - sector × 30 gives the displayed sign position.
